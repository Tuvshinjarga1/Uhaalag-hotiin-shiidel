# Сэжигтэй үйлдэл илрүүлэх систем

## Танилцуулга

Энэхүү систем нь видео камераас сэжигтэй үйлдлүүдийг илрүүлж, Next.js веб интерфэйс рүү мэдээллийг илгээдэг.

## Системийн бүрэлдэхүүн

1. **Python детекшн програм (detect/main.py)**

   - YOLOv8 ашиглан хүнийг илрүүлдэг
   - R(2+1)D загварыг ашиглан үйлдлийг таньдаг
   - Сэжигтэй үйлдэл илрүүлэхэд Next.js API рүү мэдэгдэл илгээдэг

2. **Next.js веб аппликейшн**
   - Сэжигтэй үйлдлүүдийг хүлээж авах API
   - Сэжигтэй үйлдлүүдийг харуулах хэрэглэгчийн интерфэйс
   - Real-time мэдээлэл харуулах хуудас

## Ажиллуулах

### 1. Next.js аппликейшн ажиллуулах

```bash
cd next-firebase-app
npm install
npm run dev
```

### 2. Python детекшн програм ажиллуулах

```bash
cd detect
pip install -r requirements.txt
python main.py
```

## Ерөнхий ажиллагаа

1. Python програм нь камераас бичлэг авч хүнийг илрүүлнэ
2. Илэрсэн хүний үйлдлийг загварын тусламжтай таньж шинжилнэ
3. Сэжигтэй үйлдэл илэрвэл Next.js руу API хүсэлт илгээнэ
4. Next.js веб аппликейшн нь сэжигтэй үйлдлийн мэдээллийг хүлээж авч /detection хуудас дээр харуулна

## Вэбийн интерфэйс

- **/**: Үндсэн хуудас, системийн тойм
- **/detection**: Сэжигтэй үйлдлүүдийн мэдээлэл
- **/api/alerts**: Сэжигтэй үйлдлүүдийн API
